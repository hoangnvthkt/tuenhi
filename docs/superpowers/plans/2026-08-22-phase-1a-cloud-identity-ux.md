# Tuệ Nhi Phase 1A Cloud Identity and Shared UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hoàn thiện lát cắt chạy được cho Supabase Cloud identity: schema `api`/`app_private`, profile và quyền authoritative, đăng nhập/đổi mật khẩu, session/route gate, numeric contract, toast/notification và quản trị nhân viên cơ bản.

**Architecture:** React SPA tạo một Supabase browser client dùng publishable key, rồi lấy session context qua RPC `api.get_my_session_context`; UI không suy luận quyền từ JWT metadata. PostgreSQL giữ profile, permission defaults/overrides, notification và command bảo mật trong migration có RLS/grant tối thiểu; Edge Functions chỉ làm các thao tác cần Auth Admin và luôn xác minh owner qua database trước. Tất cả thay đổi database được lưu trong migration và áp dụng vào project Cloud đã link, tuyệt đối không dùng local Supabase hoặc Docker.

**Tech Stack:** React 19.2.8, React Router 8.3.0, TanStack Query 5.101.4, React Hook Form 7.85.0, Zod 4.4.3, Supabase JS 2.112.3, Supabase CLI 2.115.0, PostgreSQL 17.6, Vitest 4.1.11, Testing Library và Playwright 1.62.1.

**Spec:** `docs/superpowers/specs/2026-08-21-internal-single-store-pos-design.md` và `docs/superpowers/specs/2026-08-22-cloud-platform-data-entry-design.md`

Implement private stable security-definer helpers:

```sql
create function app_private.has_active_profile(p_allow_password_change boolean default false)
returns boolean
language sql
stable
security definer
set search_path = ''
as $$
  select exists (
    select 1
    from api.profiles p
    where p.id = (select auth.uid())
      and p.is_active
      and (p_allow_password_change or not p.must_change_password)
  );
$$;

create function app_private.has_permission(p_permission_code text)
returns boolean
language sql
stable
security definer
set search_path = ''
as $$
  select coalesce((
    select case
      when p.role_template = 'OWNER' then true
      when d.owner_only then false
      when o.effect = 'REVOKE' then false
      when o.effect = 'GRANT' then true
      else coalesce(r.allowed, false)
    end
    from api.profiles p
    join app_private.permission_definitions d on d.code = p_permission_code
    left join app_private.role_default_permissions r
      on r.role_template = p.role_template and r.permission_code = d.code
    left join app_private.user_permission_overrides o
      on o.user_id = p.id and o.permission_code = d.code
    where p.id = (select auth.uid())
      and p.is_active
      and not p.must_change_password
  ), false);
$$;
```
